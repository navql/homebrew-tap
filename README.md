# NavQL for Homebrew

```bash
brew install --cask navql/tap/navql
```

[NavQL](https://navql.com/) is a database client for PostgreSQL, MySQL, MariaDB, SQL Server, SQLite, MongoDB and Redis. This tap installs the macOS app (Apple Silicon). The app updates itself; `brew upgrade` is not needed.

By installing NavQL you agree to its [Terms of Use](https://navql.com/terms.html) and [Privacy Policy](https://navql.com/privacy.html).

Uninstall: `brew uninstall --cask navql` (add `--zap` to also remove saved connections and settings).
